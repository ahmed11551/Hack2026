На вашем скриншоте из Reg.ru сейчас прописаны стандартные записи:

**Их нужно обязательно изменить!** У вас VPS-сервер имеет IP-адрес **`94.156.114.202`**. Если не поменять, пользователи будут попадать на пустой чужой сервер.

## 🖥️ ШАГ 2: НАСТРОЙКА ВЕБ-СЕРВЕРА NGINX НА СЕРВЕРЕ

Nginx будет принимать трафик с домена `startappai.ru` на портах 80 (HTTP) и 443 (HTTPS) и бесшовно передавать его нашему Node.js-серверу (порт 3000).

Подключитесь к VPS по SSH и выполните команды:

1. **Создайте конфигурационный файл для вашего домена:**
   ```bash
   nano /etc/nginx/sites-available/telegram-app
   ```

2. **Вставьте в открывшийся редактор следующий конфиг полностью:**
   ```nginx
   server {
       listen 80;
       server_name startappai.ru www.startappai.ru;

       location / {
           proxy_pass http://127.0.0.1:3000;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
           proxy_cache_bypass $http_upgrade;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
       }
   }
   ```
   *(Для сохранения в nano: нажмите `Ctrl + O`, затем `Enter`. Для выхода: `Ctrl + X`)*.

3. **Активируйте созданную конфигурацию в Nginx:**
   ```bash
   ln -s /etc/nginx/sites-available/telegram-app /etc/nginx/sites-enabled/
   ```

4. **Удалите стандартную заглушку Nginx (если она еще есть), чтобы избежать конфликтов:**
   ```bash
   rm -f /etc/nginx/sites-enabled/default
   ```

5. **Проверьте конфигурацию на ошибки и перезапустите Nginx:**
   ```bash
   nginx -t
   # Должно написать: nginx: configuration file /etc/nginx/nginx.conf test is successful.
   systemctl restart nginx
   ```

## 🔒 ШАГ 3: ПОЛУЧЕНИЕ БЕСПЛАТНОГО SSL (HTTPS) СЕРТИФИКАТА

Чтобы ваш Mini App открывался без предупреждений в Telegram, обязательно нужен SSL. Выпустим бесплатный автопродлевающийся сертификат Let's Encrypt.

1. **Установите Certbot и модуль для Nginx:**
   ```bash
   apt update
   apt install certbot python3-certbot-nginx -y
   ```

2. **Запустите автоматическую генерацию сертификатов:**
   ```bash
   certbot --nginx -d startappai.ru -d www.startappai.ru
   ```

3. **Ответы на вопросы утилиты Certbot:**
   * **Email:** Укажите вашу электронную почту (на случай важных предупреждений).
   * **Согласие (A/Y):** Введите **`Y`** и нажмите Enter.
   * **Рассылки (Y/N):** Введите **`N`**.
   * **Редирект на HTTPS:** Если спросит `Redirect all HTTP traffic to HTTPS?`, выберите вариант **`2`** (Redirect) или согласитесь на автоматическую настройку.

После этого Certbot автоматически допишет нужные параметры безопасности в конфигурацию Nginx. Ваш сайт начнет открываться по безопасному протоколу `https://startappai.ru`!

2. Введите команду `/mybots` и выберите вашего рабочего бота.
3. Перейдите в **Bot Settings** ➡️ **Menu Button** (или **Web App**).
4. Замените старую тестовую ссылку на новую постоянную:
   ```text
   https://startappai.ru
   ```
5. В меню **Web Apps** (если настраивали отдельную кнопку) также измените URL на `https://startappai.ru`.

### 2. Нужно ли настраивать Webhook?
У нас в Python шаблонах для робота используется автономный режим **Polling** (бот сам обращается к серверам Telegram за сообщениями). С такой архитектурой вам **не нужно** настраивать webhook в Telegram.
