# 📱 РУКОВОДСТВО ПО ЗАПУСКУ И ДЕПЛОЮ ЧЕРЕЗ TERMUX С ТЕЛЕФОНА (ANDROID)

Termux — это полноценный эмулятор Linux-терминала для Android. Через него вы можете полностью управлять вашим VPS-сервером, редактировать код, заливать файлы и запускать проект 24/7 прямо со смартфона без использования компьютера!

---

## 🎯 ОТВЕТЫ НА ВАШИ КЛЮЧЕВЫЕ ВОПРОСЫ

1. **Нужно ли заливать проект на GitHub?**
   * **Да, это самый идеальный и простой способ**. Вы загружаете проект на GitHub (можно в приватный репозиторий, чтобы код был скрыт от посторонних), а затем одной командой скачиваете (клонируете) его прямо на сервер. 
   * Или же вы можете нажать на кнопку **настройки** (иконка шестеренки справа сверху) в AI Studio и экспортировать проект как **ZIP-архив**, а затем загрузить его на сервер через Termux.

2. **Что отправлять на сервер: фронтенд или бэкенд?**
   * **Отправлять нужно ВЕСЬ проект (и фронтенд, и бэкенд вместе)!**
   * Наше приложение устроено по самой передовой full-stack схеме. Экспресс-сервер (`server.ts`) не только обрабатывает запросы к AI и логику бота, но и сам раздает скомпилированные файлы визуального интерфейса:
     * При запуске `npm run build` проект сначала компилирует ваш красивый интерфейс (фронтенд) в папку `dist/`.
     * Затем он собирает сервер (`server.ts`) в один производительный файл `dist/server.cjs`.
     * На сервере запускается один единственный процесс, который полностью обеспечивает работу и интерфейса Mini App, и API!

## 🛠️ ШАГ 1: ПОДГОТОВКА И УСТАНОВКА TERMUX НА СМАРТФОН

> ⚠️ ИЗБЕГАЙТЕ Google Play! Версия Termux в Google Play устарела и не обновляется.

1. Скачайте актуальный рабочий установщик **Termux** напрямую с Github разработчиков:
   * Перейдите по ссылке: [https://github.com/termux/termux-app/releases](https://github.com/termux/termux-app/releases)
   * Найдите последнюю версию и скачайте нужный APK (обычно `termux-app_universal.apk` или для вашей архитектуры процессора).
   * Установите APK на ваш Android-смартфон.

2. Запустите Termux. Вы увидите черную консоль Linux.

3. Обновите пакетную базу Termux и установите основные инструменты (скопируйте этот блок команд и вставьте в Termux, нажимая "Enter"):
   ```bash
   pkg update && pkg upgrade -y
   pkg install openssh git nodejs-lts zip unzip -y
   ```

## 🔑 ШАГ 2: ПОДКЛЮЧЕНИЕ К ВАШЕМУ VPS-СЕРВЕРУ ЧЕРЕЗ TERMUX

Когда вы арендуете сервер Play2Go (тариф DE-1), вам дают:
* `IP_АДРЕС` (например: `185.250.148.12`)
* Имя пользователя: `root`
* Пароль (например: `SuperStrongPass123`)

1. Введите в Termux команду подключения (замените `IP_АДРЕС` на реальный IP вашего сервера):
   ```bash
   ssh root@IP_АДРЕС
   ```
2. Консоль спросит: `Are you sure you want to continue connecting (yes/no/[fingerprint])?`
   * Наберите слово **`yes`** и нажмите Enter.
3. Консоль попросит ввести пароль: `root@IP_АДРЕС's password:`
   * Введите пароль (символы при вводе в целях безопасности **не будут отображаться**, это нормально!) и нажмите Enter.
4. 🎉 **Вы успешно подключились к мощному серверу DE-1!** Теперь всё, что вы вводите в Termux, выполняется прямо на удаленном сервере в Германии.

## 🚀 ШАГ 3: БЫСТРЫЙ ДЕПЛОЙ ПРОЕКТА НА СЕРВЕР (CHOOSE YOUR WAY)

Ниже описаны два главных способа, как залить весь наш код. Выберите один из них:

### Смелый Способ А: Через ваш GitHub репозиторий (Рекомендуемый ⭐️)

1. Зарегистрируйтесь на [github.com](https://github.com) (это бесплатно).
2. Создайте новый репозиторий (можно сделать его Private/Приватным).
3. Создайте в репозитории токен доступа (Personal Access Token), чтобы заходить без ввода паролей.
4. На сервере в консоли Termux выполните клонирование:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git /var/www/telegram-app
   cd /var/www/telegram-app
   ```

---

### Прогрессивный Способ Б: Прямой перенос ZIP-архива без GitHub

Вы можете скачать ZIP-архив вашего проекта из AI Studio на телефон, а затем загрузить его на сервер прямо через Termux.

1. В AI Studio в панели файлов или экспорта скачайте проект как ZIP-архив на телефон. Допустим, он сохранился в папку "Загрузки" под названием `react-example.zip`.
2. Разрешите Termux доступ к памяти телефона:
   ```bash
   termux-setup-storage
   ```
   *(Нажмите "Разрешить" во всплывающем окне телефона).*
3. Перейдите в папку с загрузками в Termux:
   ```bash
   cd ~/storage/downloads
   ```
4. Отправьте файл архива на ваш VPS сервер с помощью SCP одной элегантной команды:
   ```bash
   scp react-example.zip root@IP_АДРЕС:/root/
   ```
   *(Введите пароль root сервера).*
5. Подключитесь снова к вашему серверу (`ssh root@IP_АДРЕС`) и распакуйте архив:
   ```bash
   cd /root
   apt install unzip -y
   unzip react-example.zip -d /var/www/telegram-app
   cd /var/www/telegram-app
   ```

## ⚙️ ШАГ 4: ЗАПУСК ПРОЕКТА 24/7 НА СЕРВЕРЕ (ИЗ КОНСОЛИ TERMUX)

Теперь, когда вы находитесь внутри директории `/var/www/telegram-app` на вашем VPS в Termux:

1. **Создайте файл конфигурации окружения** `.env`, где пропишете ваши секретные Токены ботов и ключи API (их нельзя публиковать в открытый доступ):
   ```bash
   nano .env
   ```
   * Напишите туда ваши ключи:
     ```env
     GEMINI_API_KEY=ваш_индивидуальный_ключ
     TELEGRAM_BOT_TOKEN=токен_бота_от_botfather
     YOOKASSA_SHOP_ID=номер_магазина_юкассы
     YOOKASSA_SECRET_KEY=секретный_ключ_юкассы
     ```
   * Чтобы сохранить файл в редакторе nano: зажмите клавиши `Ctrl` + `O`, нажмите Enter, затем `Ctrl` + `X` для выхода.

2. **Запустите автоматическую сборку и PM2 менеджер**:
   ```bash
   # Установка зависимостей проекта
   npm install

   # Сборка фронтенда и бэкенда в оптимизированный единый билд
   npm run build

   # Установка менеджера фонового запуска
   npm install -g pm2

   # Запуск под защитой авторестартаpm2
   pm2 start dist/server.cjs --name "telegram-money-machine"
   pm2 save
   pm2 startup
   ```

3. 🎉 **Всё летает!** Ваш проект успешно крутится на немецком сервере под управлением безотказного демона PM2 в фоновом режиме. Если сервер перезагрузится, PM2 автоматически восстановит работу приложения.

## 🔍 ШАГ 5: ПОЛЕЗНЫЕ КОМАНДЫ ДЛЯ МОНИТОРИНГА С ТЕЛЕФОНА

Открывайте Termux в любое время суток, подключайтесь по SSH к серверу и контролируйте всё:

* **Посмотреть логи ИИ и транзакций в реальном времени:**
  ```bash
  pm2 logs telegram-money-machine
  ```
* **Посмотреть загрузку процессора и ОЗУ сервера:**
  ```bash
  pm2 monit
  ```
* **Остановить проект:**
  ```bash
  pm2 stop telegram-money-machine
  ```
* **Перезапустить проект (например, после обновления файлов):**
  ```bash
  pm2 restart telegram-money-machine
  ```
