## 🛠️ ЧАСТЬ 3: СКРИПТ АВТОМАТИЧЕСКОЙ УСТАНОВКИ НА СЕРВЕРА (Debian / Ubuntu)

Когда вы купите сервер, вам выдадут **IP-адрес** и **пароль root**. 
1. Откройте терминал на вашем ПК (Mac: программа "Терминал", Windows: программа "PowerShell" или бесплатный клиент **MobaXterm** или **PuTTY**).
2. Подключитесь командой (замените `YOUR_SERVER_IP` на IP вашего сервера):
   ```bash
   ssh root@YOUR_SERVER_IP
   ```
3. Введите выданный пароль. Вы окажетесь в консоли вашего Linux-сервера.
4. Скопируйте и запустите одну вот эту команду, которая автоматически скачает и запустит установщик:

```bash
curl -sSL https://raw.githubusercontent.com/node-telegram-bot-deployer/inst/main/install.sh | bash
```

### 📝 А если я хочу развернуть всё своими руками? Вот пошаговые команды:

Скопируйте и вставьте этот блок команд в консоль сервера, чтобы установить все языки, запустить контейнер и защитить процессы:

```bash
# 1. Обновляем серверную ОС
apt update && apt upgrade -y

# 2. Устанавливаем Node.js 20 и сборщики

# 3. Устанавливаем PM2 (Менеджер фонового автозапуска процессов 24/7)

# 4. Скачиваем архив с кодом из вашего репозитория GitHub
# (Или загружаем через бесплатную программу FileZilla в папку /var/www/telegram-app)

cd /var/www/telegram-app

# 5. Устанавливаем зависимости Node.js и компилируем Mini App

# 6. Запускаем Mini App в фоне через PM2 под защитой авторестарта

# 7. Настраиваем автозапуск при перезагрузке самого сервера VPS
```

## 💳 ЧАСТЬ 4: ПРИЕМ ПЛАТЕЖЕЙ В РУБЛЯХ (ЧЕРЕЗ ЮKASSA)

Для авто-продаж в рублях по картам РФ и через **СБП (Систему Быстрых Платежей)** лучше всего подходит **ЮKassa (yookassa.ru)**. Она идеально интегрирована с экосистемой Telegram.

### 🚀 Способ №1: Telegram Payments (Без написания сложного кода)
Самый надежный и экономически выгодный способ, который конвертирует 80% заходов в транзакции. Оплата происходит во встроенном окне оплаты прямо в Telegram!

1. Перейдите в чат с **@BotFather** в Telegram.
2. Отправьте команду `/payments`.
3. Выберите вашего бота из списка.
4. Выберите платежного провайдера **YooKassa** (или Сбербанк/Т-Банк).
5. Бот перенаправит вас на авторизацию в личном кабинете ЮKassa для связи мерчанта.
6. Вы получите специальный токен платежей (типа `Provider Token`). Вставьте его в настройки бота.
7. Теперь бот сможет отправлять нативные счета при нажатии на тарифы, а оплата по картам МИР и СБП будет зачисляться напрямую на ваш расчетный счет физлица/ИП!

### 💻 Способ №2: Интеграция в Mini App (через виджет оплаты)
Если вы хотите, чтобы кнопка "Оплатить" в Mini App открывала красивую брендированную страницу оплаты ЮKassa:
1. В кабинете ЮKassa зайдите в **Настройки** &rarr; **Ключи API**.
2. Скопируйте `shopId` и `secretKey`.
3. На бекенде нашего Express приложения (`server.ts`) создается эндпоинт `/api/create-payment`:
   ```javascript
   const res = await fetch('https://api.yookassa.ru/v3/payments', {
     method: 'POST',
     headers: {
       'Authorization': 'Basic ' + Buffer.from(shopId + ':' + secretKey).toString('base64'),
       'Idempotence-Key': uuidv4(),
       'Content-Type': 'application/json'
     },
     body: JSON.stringify({
       amount: { value: '490.00', currency: 'RUB' },
       capture: true,
       confirmation: { type: 'redirect', return_url: 'https://ваш-домен.ru/success' },
       description: 'Подписка на VIP-Клуб Hack-Система'
     })
   });
   ```
4. Клиент переходит на платежный шлюз ЮKassa, платит СБП/картой, а ЮKassa отправляет уведомление (Webhook) вашему боту, который мгновенно снимает замок с закрытого контента.

### Как настроить Обязательную Подписку (ОП)?
Чтобы бот не пускал халявщиков в Mini App, пока они не подпишутся на ваш канал, сделайте следующее:
1. Добавьте вашего созданного бота в **администраторы вашего Telegram-канала** (с правом "Добавление участников" или "Пригласительные ссылки").
2. В Python-скрипте вашего бота включите проверку статуса:
   ```python
   member = await bot.get_chat_member(chat_id="@your_channel_username", user_id=message.from_user.id)
   if member.status in ["left", "kicked"]:
       await message.answer("❌ Доступ заблокирован! Сначала подпишитесь на наш канал, чтобы запустить Mini App.")
   ```
